# ניהול חברים בקבוצות (members)

שירות נפרד ב-Railway. **לא נוגע ב-BotiX**: אין לו טבלאות משותפות, הוא לא קורא למנוע, ויש לו מספר וואטסאפ וסשן משלו (נשמר בדיסק `/data/members`).

- מכניסים מספר ומקבלים את כל הקבוצות של הזרוע, מחולקות לשתיים: קבוצות שהמספר נמצא בהן (להסרה) וקבוצות שהוא לא בהן (לצירוף).
- בכל רשימה יש חיפוש, בחירה בסימון ✓ ו"בחר הכל". אפשר לבחור רק קבוצות שבהן הזרוע מנהלת.
- הפעולות רצות אחת אחרי השנייה, עם השהיה שאפשר לשנות בהגדרות. לכל קבוצה מוצגת תוצאה, ואם הפעולה נכשלה מוצגת גם הסיבה.

משתני סביבה: `ACCESS_CODE` (קוד כניסה), `SESSION_SECRET`, `DATA_DIR` (ברירת מחדל `/data/members`). להדגמה: `DEMO=1`.
